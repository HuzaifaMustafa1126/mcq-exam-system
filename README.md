Full-stack projects — MCQ Examination System 🎉
A modern, responsive, and production-ready examination platform designed to simplify the way educational institutions create, manage, and conduct online examinations.
The platform is built with a strong focus on performance, security, scalability, and user experience, providing dedicated dashboards for administrators, teachers, and students.
✨ Key Features
 ✅ Beautiful Modern UI/UX (Dark Theme)
 ✅ Secure JWT Authentication
 ✅ Role-Based Access (Admin, Teacher & Student)
 ✅ Subject & Question Bank Management
 ✅ Exam Creation & Scheduling
 ✅ Real-Time Result Generation
 ✅ Performance Analytics Dashboard
 ✅ Responsive Design
 ✅ Fast & Optimized Architecture
 ✅ Ready for Production Deployment
