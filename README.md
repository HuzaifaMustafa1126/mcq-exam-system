# 🎓 MCQ Examination System

A modern, responsive, production-ready examination platform.

## ✨ Features

- ✅ JWT Authentication
- ✅ Role Based Access
- ✅ Admin Dashboard
- ✅ Teacher Dashboard
- ✅ Student Dashboard
- ✅ Question Bank
- ✅ Exam Creation
- ✅ Result Generation
- ✅ Performance Analytics
- ✅ Responsive UI

## 🛠 Tech Stack

### Frontend
- React.js
- Vite
- Tailwind CSS
- React Router
- Axios

### Backend
- Node.js
- Express.js
- JWT
- bcrypt

### Database
- MySQL
